# Random_password_generator
The Random Password Generator is a Python-based application that generates strong and secure passwords according to the user's requirements. The user can select the password length and choose different character types such as uppercase letters, lowercase letters, numbers, and special symbols.

The advanced version provides a GUI interface using Tkinter, secure password generation using the secrets module, a password strength indicator, clipboard copying, an option to exclude ambiguous characters, and a history of the last five generated passwords.
